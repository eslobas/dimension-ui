## Why `action` and `accent` are different

The brand blue `#4f8cff` only reaches **3.2:1** with white text, which fails WCAG AA for normal-size text. Buttons therefore use `action` (`#2f6fe0`, 4.7:1), while the brand blue stays for accents on dark backgrounds, where it reaches 6.2:1. This rule is enforced by `src/tokens/contrast.test.ts`.
